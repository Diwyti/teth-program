2. НОМЕР И УСЛОВИЕ ИНДИВИДУАЛЬНОГО ВАРИАНТА
================================================================================
Вариант №1: Вычисление параметров трехзначного целого числа и базовые арифметические преобразования.

Условие задачи:
1. Запросить у пользователя ввод целого трехзначного положительного числа N.
2. Вычислить сумму и произведение его цифр.
3. Извлечь последнюю цифру числа с помощью операции взятия остатка по модулю 10.
4. Получить число без последней цифры с помощью целочисленного деления на 10.
5. Вычислить результат деления исходного числа на сумму его цифр (как с плавающей точкой, так и нацело), а также возвести сумму цифр в квадрат.

================================================================================
3. ВХОДНЫЕ И ВЫХОДНЫЕ ДАННЫЕ
================================================================================
Входные данные:
- N - целое трехзначное число, вводимое пользователем с клавиатуры (тип данных: int).

Выходные данные:
- last_digit - последняя цифра числа (тип int).
- truncated_num - число без последней цифры (тип int).
- digits_sum - сумма цифр числа (тип int).
- digits_prod - произведение цифр числа (тип int).
- division_float - точный результат деления числа на сумму цифр (тип float).
- division_int - целочисленный результат деления числа на сумму цифр (тип int).
- sum_sq - квадрат суммы цифр (тип int).

================================================================================
4. АЛГОРИТМ РЕШЕНИЯ
================================================================================
1. Запросить у пользователя ввод строки с помощью функции input() и преобразовать ее к целочисленному типу int().
2. Извлечь цифры трехзначного числа N:
   - Третья (последняя) цифра: d3 = N % 10
   - Вторая цифра: d2 = (N // 10) % 10
   - Первая цифра: d1 = N // 100
3. Вычислить сумму цифр: S = d1 + d2 + d3.
4. Вычислить произведение цифр: P = d1 * d2 * d3.
5. Удалить последнюю цифру числа: N_trunc = N // 10.
6. Выполнить точное деление N / S и целочисленное деление N // S.
7. Вычислить квадрат суммы цифр: S**2.
8. Вывести полученные результаты на экран с пояснительным текстом.

================================================================================
5. ИСХОДНЫЙ КОД PYTHON
================================================================================
# --- Программа обработки трехзначного числа ---

def main():
    # 1. Ввод данных
    user_input = input("Введите целое трехзначное число: ")
    num = int(user_input)
    
    # 2. Выделение цифр числа
    d3 = num % 10          # Последняя цифра
    d2 = (num // 10) % 10  # Средняя цифра
    d1 = num // 100        # Первая цифра
    
    # 3. Вычисления
    digits_sum = d1 + d2 + d3
    digits_prod = d1 * d2 * d3
    truncated_num = num // 10
    
    div_float = num / digits_sum
    div_int = num // digits_sum
    sum_squared = digits_sum ** 2
    
    # 4. Вывод результатов
    print("\n--- Результаты обработки ---")
    print(f"Исходное число: {num} (тип: {type(num).__name__})")
    print(f"Цифры числа: {d1}, {d2}, {d3}")
    print(f"Последняя цифра (num % 10): {d3}")
    print(f"Число без последней цифры (num // 10): {truncated_num}")
    print(f"Сумма цифр: {digits_sum}")
    print(f"Произведение цифр: {digits_prod}")
    print(f"Деление числа на сумму цифр (/): {div_float:.2f} (тип: {type(div_float).__name__})")
    print(f"Целочисленное деление на сумму цифр (//): {div_int} (тип: {type(div_int).__name__})")
    print(f"Квадрат суммы цифр (** 2): {sum_squared}")

if __name__ == "__main__":
    main()

КОНТРОЛЬНЫЕ ВОПРОСЫ

1. Что представляет собой переменная в Python?
Ответ: Переменная в Python - это именованная ссылка (связь), указывающая на объект, хранящийся в динамической памяти. Переменная сама по себе не содержит значение, а хранит адрес объекта.

2. Какие основные типы данных используются в Python?
Ответ: К основным типам относятся: целые числа (int), вещественные числа (float), строки (str), логический тип (bool), списки (list), кортежи (tuple), словари (dict) и множества (set).

3. Чем int отличается от float?
Ответ: Тип int предназначен для работы с целыми числами произвольной длины без дробной части (например, 10, -5). Тип float хранит вещественные числа с плавающей точкой (дробные числа, например, 10.5, -0.01).

4. Как работает функция input()?
Ответ: Функция input([prompt]) выводит на экран необязательную строку-подсказку prompt и приостанавливает выполнение программы до тех пор, пока пользователь не введет данные с клавиатуры и не нажмет клавишу Enter. Функция всегда возвращает введенные данные в виде строки (str).

5. Почему результат input() часто необходимо преобразовывать?
Ответ: Так как input() всегда возвращает текстовую строку, выполнение математических операций с полученным результатом приведет к строковым операциям (например, "10" + "5" даст "105", а не 15). Для арифметических расчетов строку необходимо явно перевести в числовой тип.

6. Для чего используются int() и float()?
Ответ: Функции int() и float() используются для явного приведения типов - преобразования совместимых данных (например, строк "123" или "3.14") в целое число или число с плавающей точкой соответственно.

7. Чем / отличается от //?
Ответ: Оператор / выполняет точное (вещественное) деление и всегда возвращает результат типа float (например, 7 / 2 = 3.5). Оператор // выполняет целочисленное деление с округлением результата в меньшую сторону до целого числа (например, 7 // 2 = 3).

8. Что делает оператор %?
Ответ: Оператор % находит остаток от целочисленного деления первого числа на второе (например, 7 % 2 = 1).

9. Для чего используется оператор **?
Ответ: Оператор ** используется для возведения числа в степень (например, 2 ** 3 = 8).

10. Как определить тип переменной с помощью type()?
Ответ: Функция type(x) принимает объект или переменную x в качестве аргумента и возвращает имя его класса/типа данных (например, type(5) вернет <class 'int'>).

11. Что такое преобразование типов?
Ответ: Преобразование (приведение) типов - это процесс конвертации значения из одного типа данных в другой. Оно бывает неявным (автоматически выполняемым интерпретатором) и явным (вызываемым программистом с помощью функций int(), float(), str() и т.д.).

12. Что произойдет при попытке int("Python")?
Ответ: Программа завершится с ошибкой ValueError: invalid literal for int() with base 10: 'Python', так как строка "Python" не состоит из цифр и не может быть интерпретирована как десятичное целое число.

13. Как получить последнюю цифру целого числа?
Ответ: Взять остаток от деления числа на 10 с помощью оператора % (например, 123 % 10 = 3).

14. Как удалить последнюю цифру целого числа?
Ответ: Выполнить целочисленное деление числа на 10 с помощью оператора // (например, 123 // 10 = 12).

15. Почему выбор правильного типа данных важен?
Ответ: Выбор корректного типа данных обеспечивает точность и правильность математических операций, предотвращает ошибки во время выполнения программы, позволяет эффективно расходовать оперативную память и делает код понятным и поддерживаемым.
